Déposer une version

Comment ça marche
  • Télécharge une version, ajoute une idée avec ChatGPT, Claude, Copilot ou autre, puis dépose le fichier obtenu.
  • Ajouter, pas remplacer : ce qui existe déjà doit continuer à fonctionner.

Prompt conseillé :

Voici la dernière version du programme.
Je veux ajouter UNE nouvelle fonctionnalité : [décris précisément ton idée].

Contraintes :
- toutes les fonctionnalités existantes doivent être conservées ;
- ne supprime aucune règle déjà présente ;
- modifie uniquement ce qui est nécessaire ;
- vérifie les interactions avec les fonctions existantes ;
- corrige tout conflit éventuel ;
- renvoie-moi le fichier HTML complet, prêt à être enregistré et testé.
