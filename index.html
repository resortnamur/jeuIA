La règle d’or

Ajouter, pas remplacer.

Une seule améliorationUne règle, un bonus, un ennemi, un effet, une idée absurde…
IA au choixChatGPT, Claude, Grok, Copilot… peu importe : le défi porte sur la manière de guider l’IA.
Non-régressionLa nouvelle fonction ne doit pas supprimer ou casser les précédentes.
Relais propreOn ne publie que lorsqu’on a réellement testé la version obtenue.
Afficher un prompt conseillé 
Voici la dernière version du programme.
Je veux ajouter UNE nouvelle fonctionnalité : [décris précisément ton idée].

Contraintes :
- toutes les fonctionnalités existantes doivent être conservées ;
- ne supprime aucune règle déjà présente ;
- modifie uniquement ce qui est nécessaire ;
- vérifie les interactions avec les fonctions existantes ;
- corrige tout conflit éventuel ;
- renvoie-moi le fichier HTML complet, prêt à être enregistré et testé.
